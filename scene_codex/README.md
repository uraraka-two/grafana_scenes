# scene_codex アプリケーション

このディレクトリには、React + TypeScript + Vite で構築された Grafana Scenes アプリケーションが含まれています。開発サーバーの起動やビルドは npm スクリプトで行います。

## セットアップ

初回のみ依存パッケージをインストールしてください。

```bash
npm install
```

## 開発サーバーの起動

Vite の開発サーバーを起動します。既定ポートは `5173` です。

```bash
npm run dev
```

## プロダクションビルド

本番用にビルドする場合は以下を実行します。

```bash
npm run build
```

## ビルド結果のプレビュー

ビルド成果物をローカルで確認するためのプレビューサーバーを起動します。

```bash
npm run preview
```
